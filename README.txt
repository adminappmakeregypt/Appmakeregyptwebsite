1. Extract this ZIP.
2. Upload index.html, styles.css, app.js, favicon.png, robots.txt, .nojekyll and the assets folder to your GitHub repository root. Keep assets as a folder; do not flatten it.
3. In GitHub Settings > Pages select main branch / (root).
4. Wait for deployment and refresh the website.
