TEST RESULTS — AppMaker Egypt website v3 (Promotions)
Date: 2026-10-20

Method: the site was served locally and exercised in a real Chromium browser (Playwright).
Because the sandbox has no access to your Firebase password, Firebase was replaced by an
in-memory simulation implementing the same API. Everything about the pages themselves
(rendering, forms, validation, filtering, ordering, live updates, RTL, mobile layout)
was genuinely exercised; the Firebase round-trip and the security rules themselves
were NOT executed against the real service (see "Not verified" below).

34/34 checks passed:

Admin (Manage Promotions page)
- Login form is shown; the management area is hidden before login and on direct navigation.
- Signing in with a different account is rejected ("not authorized") and signed back out.
- Signing in with appmakeregypt@gmail.com opens the management area; it stays open after refresh.
- Create + Publish: promotion saved with photo stored under promotions/<document-id>/, createdBy
  recorded, created/updated dates shown in the list.
- Save Draft keeps the offer hidden from the public page.
- Edit updates the SAME document (row count unchanged — no duplicates).
- Publish/Unpublish toggle works from the list.
- Delete asks for confirmation and removes the offer (and its photo).
- Preview shows the exact card visitors will see.
- Replacing a photo stores the new file and removes the old file from storage.

Public homepage
- The offers section is hidden when there is nothing to show.
- It appears live (no page reload, no code change) when an offer is published.
- Only Published offers within their start/end dates are shown; drafts, unpublished,
  future and expired offers are hidden.
- The payment button opens the exact configured payment URL with the configured button text.
- Offers are sorted by display order.
- Arabic titles/text render right-to-left; the section translates with the language toggle
  (العروض / العروض الحالية) and the rest of the site is unchanged.
- Mobile (390px): cards render and fit the screen.
- No console or page errors in any test.

Files changed vs v2
- index.html  — added the "Current Offers" section (hidden until an offer is published),
  a "Promotions" link in the desktop/mobile/footer navigation, and the promotions.js script tag.
- app.js      — added "Promotions"/"العروض" and section title translations (English + Arabic).
- styles.css  — added promotion card styling only; nothing existing was modified.
- NEW promotions.js            — public live display of published offers.
- NEW promotions-firebase.js   — shared setup reusing the clinic's Firebase project (bookmydoctor-6c93c).
- NEW promotions-admin.html    — the Manage Promotions page.
- NEW promotions-admin.js      — login gate + create/edit/preview/publish/unpublish/delete logic.
- NEW firestore.rules          — your clinic's current rules PLUS the promotions block
  (public reads of published offers only; all writes restricted to appmakeregypt@gmail.com).
- NEW storage.rules            — your clinic's current rules PLUS the promotions block
  (anyone can view offer photos; only appmakeregypt@gmail.com can upload/replace/delete;
  JPG/PNG/WebP only, max 5 MB).
- README.txt, TEST_RESULTS.txt — updated.

Data structure (Firestore collection "promotions", one document per offer):
title, imageUrl, imagePath, description, paymentUrl, buttonText,
status (draft | published | unpublished), displayOrder,
startDate, endDate, createdAt, updatedAt, createdBy.
Photos live in Firebase Storage under promotions/<document-id>/photo.<ext>.
